# Световой инструмент / Light Organ

Интерактивный музыкальный инструмент на Arduino: три фоторезистора считывают свет и тень, а браузер превращает их значения в три слоя звука.

## Что внутри

- три звуковых режима;
- подключение Arduino через Web Serial;
- инструкция для новичков на русском и английском;
- интерактивная 3D-схема подключения;
- пошаговая сборка с координатами стандартного breadboard.

## Что понадобится

- Arduino Uno или Nano;
- breadboard;
- 3 фоторезистора LDR;
- 3 резистора по 10 кОм;
- минимум 6 проводов «папа–мама» и 5 проводов «папа–папа»;
- USB-кабель.

## Запуск

1. Скачайте [Arduino IDE](https://www.arduino.cc/en/software).
2. Откройте `index.html` и перейдите во вкладку «Инструкция».
3. Соберите схему по шагам и загрузите приведённый на странице код в Arduino.
4. Закройте Serial Monitor в Arduino IDE.
5. Откройте `index.html` в настольном браузере с поддержкой Web Serial.
6. Нажмите «Включить звук», затем «Подключить Arduino».

Для публикации на GitHub Pages откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

## Приватность

Проект работает локально в браузере. В репозитории нет API-ключей, паролей или серверной конфигурации.
